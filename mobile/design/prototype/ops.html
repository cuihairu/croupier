P5 远程操作入口 · 设计说明

布局

自上而下 = 风险提示条 → 函数选择（按 scope 过滤）→ Schema 驱动的参数表单 → 主操作对（预览影响 / 发起执行）→ 最近执行记录。把「风险」放在页面第一个元素而非按钮旁的小字——进页面先知道自己手里拿的是什么。

关键交互

① 参数表单完全由函数契约 JSON Schema 生成（与桌面端同源，required/枚举/默认值自动校验）；② 「发起执行」≠ 直接执行：高风险函数自动进入审批工作流（按钮态变为「发起审批」语义），低风险函数直发任务流；③ 「预览影响」在执行前展示目标对象状态（如玩家在线状态、账号资产），降低误操作；④ 幂等键自动生成，弱网重试不重复生效。

信息层级

函数名一律 mono——它是机器标识不是文案；审批态用琥珀、成功绿、失败红三色贯通「提示条→函数 chip→执行记录」，让审批语义在一屏内三次强化；执行记录位于次屏（列表页可滚动查看），首屏保持「选函数→填参数→执行」一气呵成。
