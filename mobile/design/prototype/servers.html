P3 服务器列表与状态 · 设计说明

布局

搜索 + 状态过滤 chips（带计数）→ 节点卡列表。每张卡三层：身份层（状态点 + 节点名 + 环境 chip + 版本/函数数/心跳）、指标层（CPU/MEM 迷你条 + 延迟）、动作层（详情/重连）。异常卡用红色描边升出列表。

关键交互

① 状态点即健康语言：绿=在线（呼吸光晕）、琥珀=维护/drain、灰=离线、红=异常离线，配色与桌面端运维台一致；② 离线卡内联「尝试重连」直达 agent 重连指令（走任务模型，进度推送回告警）；③ 下拉刷新 + 30s 自动轮询心跳，弱网下降级为手动刷新。

信息层级

运维扫视顺序 = 状态 → 身份 → 资源 → 动作。版本与函数数用 mono 小字降噪；延迟按阈值变色（<80ms 绿）。过滤 chips 的计数让「离线 2」无需进列表就能感知规模。
