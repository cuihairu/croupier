## Before → After 对比

### Before (go-zero)
```go
func RegisterHandlers(server *rest.Server, serverCtx *svc.ServiceContext) {
    // 公开路由（无认证）
    server.AddRoutes(
        []rest.Route{
            {
                Method:  http.MethodPost,
                Path:    "/login",
                Handler: auth.LoginHandler(serverCtx),
            },
            {
                Method:  http.MethodPost,
                Path:    "/logout",
                Handler: auth.LogoutHandler(serverCtx),
            },
        },
        rest.WithPrefix("/api/v1/auth"),
    )

    // 需要认证的路由
    server.AddRoutes(
        rest.WithMiddlewares(
            []rest.Middleware{serverCtx.Authority},
            []rest.Route{
                {
                    Method:  http.MethodGet,
                    Path:    "/terms",
                    Handler: terms.TermsListHandler(serverCtx),
                },
            }...,
        ),
        rest.WithPrefix("/api/v1"),
    )

    // 普通路由组
    server.AddRoutes(
        []rest.Route{
            {
                Method:  http.MethodGet,
                Path:    "/",
                Handler: admin.AdminsListHandler(serverCtx),
            },
            {
                Method:  http.MethodPost,
                Path:    "/",
                Handler: admin.AdminCreateHandler(serverCtx),
            },
            {
                Method:  http.MethodGet,
                Path:    "/:id",
                Handler: admin.AdminDetailHandler(serverCtx),
            },
        },
        rest.WithPrefix("/api/v1/admin"),
    )
}
```

### After (Gin)
```go
func RegisterHandlers(r *gin.Engine, serverCtx *svc.ServiceContext) {
    v1 := r.Group("/api/v1")

    // 公开路由（无认证）
    authGroup := v1.Group("/auth")
    {
        authGroup.POST("/login", auth.LoginHandler(serverCtx))
        authGroup.POST("/logout", auth.LogoutHandler(serverCtx))
    }

    // 需要认证的路由（使用 serverCtx.Authority 中间件）
    protected := v1.Group("/")
    protected.Use(serverCtx.Authority)
    {
        protected.GET("/terms", terms.TermsListHandler(serverCtx))
        protected.PUT("/terms", terms.TermUpsertHandler(serverCtx))
        protected.DELETE("/terms", terms.TermDeleteHandler(serverCtx))
    }

    // 管理员路由
    adminGroup := v1.Group("/admin")
    {
        adminGroup.GET("/", admin.AdminsListHandler(serverCtx))
        adminGroup.POST("/", admin.AdminCreateHandler(serverCtx))
        adminGroup.GET("/:id", admin.AdminDetailHandler(serverCtx))
        adminGroup.PUT("/:id", admin.AdminUpdateHandler(serverCtx))
        adminGroup.DELETE("/:id", admin.AdminDeleteHandler(serverCtx))
        adminGroup.POST("/:id/password-reset", admin.AdminPasswordResetHandler(serverCtx))
    }
}
```

## 注意

- go-zero 的 `rest.WithMiddlewares` 只在 routes.go 末尾出现一次（terms 路由），对应 Gin 的 `protected` 路由组
- 大多数路由**没有**使用 `serverCtx.Authority`，认证逻辑在 logic 层通过 `utils.RequireAnyPermission` 实现
- `routes` 子包中的 `GetRoutesHandler` 需要单独处理（返回路由列表的 meta 接口）
- 路由文件不再由 goctl 生成，需要手动维护，建议按模块拆分为多个文件
