# Croupier 配置管理系统使用指南

## 🎯 概述

Croupier配置管理系统是一个企业级的、高度可扩展的配置管理解决方案，支持多源配置、动态加载、热重载和全面验证。

## 🚀 快速开始

### 1. 基本使用

```go
package main

import (
    "context"
    "log"
    "github.com/cuihairu/croupier/internal/config"
)

func main() {
    ctx := context.Background()

    // 创建配置管理器
    manager, err := config.NewManager(ctx)
    if err != nil {
        log.Fatal(err)
    }
    defer manager.Close()

    // 从文件加载配置
    err = manager.LoadFromFile("configs/app.yaml")
    if err != nil {
        log.Fatal(err)
    }

    // 获取配置
    appConfig := manager.GetAppConfig()
    log.Printf("应用: %s v%s", appConfig.Name, appConfig.Version)
}
```

### 2. 多源配置

```go
// 从多个源加载配置
sources := []*config.ConfigSource{
    // 基础配置文件（必需）
    config.NewConfigSource(config.SourceTypeFile, "/etc/croupier/base.yaml", true),
    // 环境特定配置文件
    config.NewConfigSource(config.SourceTypeFile, "/etc/croupier/prod.yaml", false),
    // 环境变量覆盖
    config.NewEnvConfigSource("CROUPIER_", false),
    // 远程配置中心
    config.NewRemoteConfigSource(
        "https://config.example.com/api/v1/config",
        map[string]string{"Authorization": "Bearer token"},
        false,
    ),
}

err := manager.LoadFromMultiple(sources)
```

## 📁 配置结构

### 主配置层次

```
Config
├── App              # 应用配置
├── Network          # 网络配置
│   └── Server      # 服务器配置
├── Database         # 数据库配置
│   ├── Primary     # 主数据库
│   └── ReadOnly    # 只读副本
├── Security         # 安全配置
├── Observability    # 可观测性配置
├── Business         # 业务配置
└── Storage          # 存储配置
```

type AppConfig struct {

## ✅ 配置验证

### 内置验证规则

1. **应用验证** - 名称、版本、环境
2. **网络验证** - 端口范围、TLS配置
3. **数据库验证** - 连接参数、连接池
4. **安全验证** - JWT密钥长度、密码策略
5. **可观测性验证** - 日志级别、指标配置
6. **业务验证** - 游戏配置、函数配置
7. **存储验证** - 存储提供商配置

### 使用验证

```go
// 创建验证器
validator := config.NewDefaultValidator()

// 添加自定义验证规则
validator.AddRule(config.NewCustomValidationRule(
    "PortRangeValidation",
    "验证端口范围",
    func(config *config.Config) error {
        if config.Network.Server.HTTPPort == config.Network.Server.GRPCPort {
            return fmt.Errorf("HTTP和gRPC端口不能相同")
        }
        return nil
    },
))

// 验证配置
err := validator.Validate(configStruct)
if err != nil {
    log.Fatal("配置验证失败:", err)
}
```

### 便捷验证函数

```go
// 端口验证
err := config.ValidatePort(8080)

// URL验证
err := config.ValidateURL("https://example.com")

// 邮箱验证
err := config.ValidateEmail("user@example.com")

// 数值范围验证
err := config.ValidateRange(port, 1, 65535, "端口")

// 时间段验证
err := config.ValidateDuration(time.Hour)

// 字符串枚举验证
err := config.ValidateStringEnum(env, []string{"dev", "test", "prod"}, "环境")
```

## 🔄 热重载和监听

### 配置监听

```go
// 监听配置变更
manager.WatchConfig(ctx, func(config *config.Config, err error) {
    if err != nil {
        log.Printf("配置监听错误: %v", err)
        return
    }

    log.Printf("配置已更新:")
    log.Printf("  HTTP端口: %d", config.Network.Server.HTTPPort)
    log.Printf("  数据库: %s:%d/%s",
        config.Database.Primary.Host,
        config.Database.Primary.Port,
        config.Database.Primary.Database,
    )
})
```

### 重启信号处理

```go
// 监听配置重启信号
restartChan := manager.RestartChan()
go func() {
    for range restartChan {
        log.Println("收到配置重启信号，准备重启服务...")
        // 优雅关闭现有服务
        // 重新初始化服务组件
        // 启动新服务实例
    }
}()
```

### 手动重新加载

```go
// 重新加载所有配置源
err := manager.Reload()
if err != nil {
    log.Printf("重新加载配置失败: %v", err)
} else {
    log.Println("配置重新加载成功")
}
```

## 🔐 安全最佳实践

### 敏感信息管理

```yaml
# ✅ 好的做法 - 使用环境变量
security:
  jwt:
    secret: "${JWT_SECRET}"
database:
  primary:
    password: "${DB_PASSWORD}"

# ❌ 坏的做法 - 直接在配置文件中存储
security:
  jwt:
    secret: "hardcoded-secret"

  primary:
    password: "hardcoded-password"
```

## 🚀 部署配置

### Docker 部署

```dockerfile
# Dockerfile
FROM golang:1.21-alpine AS builder

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download

COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -o croupier ./cmd/server

FROM alpine:latest
RUN apk --no-cache add ca-certificates
WORKDIR /root/

COPY --from=builder /app/croupier .
COPY --from=builder /app/configs ./configs

# 设置环境变量
ENV CROUPIER_APP_ENV=production
ENV CROUPIER_APP_NAME=croupier
ENV CROUPIER_APP_VERSION=1.0.0

EXPOSE 8080 9090
CMD ["./croupier"]
```

## 🔍 故障排除

### 常见问题

1. **配置文件解析失败**
   ```bash
   # 检查YAML语法
   yamllint configs/app.yaml

   # 验证JSON格式
   python -m json.tool configs/app.json
   ```

2. **环境变量未生效**
   ```go
   // 检查环境变量前缀
   envManager := config.NewEnvManager("CROUPIER_")
   envInfo := envManager.GetEnvInfo()

   for key, info := range envInfo {
       fmt.Printf("%s = %v\n", key, info.Value)
   }
   ```

3. **配置验证失败**
   ```go
   // 详细的验证错误信息
   validator := config.NewDefaultValidator()
   err := validator.Validate(config)
   if err != nil {
       fmt.Printf("验证失败详情: %+v\n", err)
   }
   ```

4. **热重载不工作**
   ```go
   // 检查配置监听器是否正确设置
   manager.WatchConfig(ctx, func(config *config.Config, err error) {
       log.Printf("配置监听器被调用: err=%v", err)
   })
   ```

### 调试工具

func DebugConfig(manager *config.Manager) {

    config := manager.GetConfig()

    // 导出配置用于调试
    jsonConfig, _ := manager.Export("json")
    fmt.Printf("当前配置:\n%s\n", string(jsonConfig))

    // 检查配置源

    validator := config.NewDefaultValidator()

        fmt.Printf("配置验证错误: %v\n", err)
    } else {
        fmt.Println("配置验证通过")
    }
}
