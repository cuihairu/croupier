# 组合页编辑器 × 参考产品对比拆分分析

> 样品（可亲手操作）：**amis-editor** http://192.168.5.5:8001 ｜ **Appsmith** http://192.168.5.5:8002
> 方法：逐交互维度对比参考产品的真实行为与当前实现，标注差距与改造项。本文是事实清单，不做辩护。
> **2026-08-30 更新：第三节改造清单已全部落地（见状态列），使用方式见 [组合页编辑器 V3 使用指南](./composite-editor-v3.md)。**

## 一、总体判断

当前实现的问题是**交互完整度**：单看每个功能都"有"，但对照成熟产品的操作流，
关键环节缺失或形态错误，导致用户无法形成连贯操作。最大的三个断层：

1. **空画布形态错误**（曾放强制向导——参考产品从无此模式）
2. **弹窗内编辑断层**（参考产品可进入弹窗内部直接编辑；当前只能在收纳区点一行摘要）
3. **函数数据源与组件的关系弱**（参考产品：数据源→任意组件反复绑定是核心循环）

## 二、逐维度对比

### 1. 新建页面 / 进入编辑器

|        | Appsmith                            | amis-editor  | 当前实现               | 差距                       |
| ------ | ----------------------------------- | ------------ | ---------------------- | -------------------------- |
| 新建时 | 选「模板 / 空白应用」**一次性**选择 | 直接空白画布 | 曾强制全屏向导（已删） | ✅ 已改齐：空画布=虚线占位 |

### 2. 画布空态

|               | 参考产品做法                                           | 当前实现                     | 改造项    |
| ------------- | ------------------------------------------------------ | ---------------------------- | --------- |
| Appsmith/amis | 大虚线区域「拖拽组件到这里」，**左栏组件面板永远可见** | RootDropZone（已恢复同形态） | ✅ 已改齐 |

### 3. 添加组件

|          | Appsmith                                                                     | amis-editor                              | 当前实现                                                                          |
| -------- | ---------------------------------------------------------------------------- | ---------------------------------------- | --------------------------------------------------------------------------------- |
| 方式     | 拖拽 widget 到画布**任意落点**（有对齐线/吸附），或点击直接放置              | 拖拽插入，**落点有插入线指示**；也可点击 | 拖拽（落点=节点后/根）+ 点击（根末尾）                                            |
| 数据组件 | **widget 与 Query 解耦**：先建 Query（数据源），任何 widget 可绑定任意 Query | CRUD 组件选 API                          | 函数即组件（拖函数=建组件）；已支持换绑/多实例                                    |
| 差距     | —                                                                            | —                                        | ①拖拽无**对齐线/落点指示线**（参考产品有明确视觉反馈）②无点击直接放的即时反馈动画 |

**改造项 A（高）**：拖拽时画布内显示插入位置指示线（dnd-kit droppable 已有目标计算，缺视觉）。

### 4. 选中与快捷操作

|          | Appsmith                                | amis-editor                                                   | 当前实现                                                       |
| -------- | --------------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------- |
| 选中反馈 | 8 控制点 + 悬浮工具条（复制/删除/对齐） | 选中框 + 工具条（上移/下移/复制/删除/**选择父级**）+ 右键菜单 | 选中蓝框 + 右上角图标（复制/删除）                             |
| 多选     | 框选/Shift                              | 无                                                            | 无                                                             |
| 差距     | —                                       | —                                                             | ①无「选择父级」（嵌套容器内选中子级后想选容器很难）②无右键菜单 |

**改造项 B（中）**：选中工具条加「选择父级」；容器嵌套后子节点可选。

### 5. 属性配置（右侧面板）

|          | Appsmith                                                   | amis-editor                          | 当前实现                                               |
| -------- | ---------------------------------------------------------- | ------------------------------------ | ------------------------------------------------------ |
| 结构     | 三 Tab：**属性 / 样式 / 事件**（事件=onClick 下拉动作+JS） | Tab：常规/外观/高级（schema 自描述） | 单页滚动（rjsf 字段 + 事件/行操作特殊渲染）            |
| 数据绑定 | `{{query1.data}}` 响应式表达式 + **下拉选择**              | 变量选择器                           | 同名字段自动合并（无显式绑定 UI）                      |
| 差距     | —                                                          | —                                    | ①无「事件」Tab 分区——动作编辑藏在滚动底部；②字段分组弱 |

**改造项 C（高）**：属性面板分区（基础/数据/事件），事件固定底部不随滚动丢失。

### 6. 弹窗（Modal）编辑 ⚠️ 最大断层

|          | Appsmith                                                   | amis-editor                                                                         | 当前实现                                                |
| -------- | ---------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------- |
| 弹窗形态 | ModalWidget 在**画布上占位**，点击即选中，双击进入内部编辑 | dialog 组件画布显示轮廓，**点击进入弹窗内部画布**（画布切换为弹窗内容，面包屑返回） | 收纳区一行卡片，点表单标签才选中                        |
| 差距     | —                                                          | —                                                                                   | **无法在画布上直接看到/编辑弹窗内部布局**；多表单不支持 |

**改造项 D（最高）**：画布内弹窗占位卡片**可展开为内嵌画布**（点击弹窗体→画布切换显示弹窗内部，顶栏面包屑「页面 / 弹窗名」返回），modal 内允许多组件。这是参考产品弹窗编辑的标准形态。

### 7. 预览

|      | Appsmith                 | amis-editor | 当前实现                                      |
| ---- | ------------------------ | ----------- | --------------------------------------------- |
| 切换 | 顶栏「编辑/预览」即时    | 顶栏即时    | 顶栏「预览」                                  |
| 差异 | 预览态保留画布位置上下文 | 同          | 预览=独立渲染（复用发布渲染器，所见即发布）✅ |
| 差距 | —                        | —           | 基本对齐                                      |

### 8. 数据调试（试跑）

|      | Appsmith                                         | amis-editor | 当前实现                                   |
| ---- | ------------------------------------------------ | ----------- | ------------------------------------------ |
| 形态 | **底部常驻面板**：Query 结果/错误/参数，随时查看 | 有调试面板  | 无（预览态可执行，但编辑态无即时数据查看） |
| 差距 | —                                                | —           | 编辑态选中表格组件无法「跑一下看看数据」   |

**改造项 E（中）**：编辑态底部可折叠「数据」面板：选中 fn 组件一键试跑（invokeFunction），结果表格展示（V2 曾有，V3 丢失）。

### 10. 保存/发布

|      | Appsmith                         | 当前实现                                    |
| ---- | -------------------------------- | ------------------------------------------- |
