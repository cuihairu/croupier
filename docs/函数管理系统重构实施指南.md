# Croupier 函数管理系统重构实施指南

## 概述

本指南详细说明了Croupier函数管理系统重构的实施过程，包括架构设计、组件开发、页面重构和部署策略。

## 重构目标

### 主要问题
- **单一页面过载**：原有GmFunctions页面655行代码，功能过于集中
- **用户体验不佳**：菜单分散，导航困难，学习曲线陡峭
- **代码复用性低**：相似功能重复实现，维护成本高
- **扩展性受限**：难以支持版本管理、灰度发布等高级功能

### 解决方案
- **5个专注页面**：函数目录、函数调用、实例管理、权限分配、函数包管理
- **5个通用组件**：FunctionListTable、FunctionDetailPanel、FunctionFormRenderer、FunctionCallHistory、RegistryViewer
- **统一菜单结构**：集中的函数管理菜单，清晰导航
- **模块化架构**：单一职责，高内聚低耦合

## 架构设计

### 组件层次结构
```
Function Management System
├── Pages/
│   ├── Functions/Directory/          # 函数目录页面
│   ├── Functions/Invoke/             # 函数调用页面 (新)
│   ├── Functions/Instances/          # 实例管理页面
│   ├── GmFunctions/                  # 原有调用页面 (保持兼容)
│   ├── Assignments/                  # 权限分配页面
│   └── Packs/                        # 函数包管理页面
├── Components/
│   ├── FunctionListTable/            # 通用函数列表组件
│   ├── FunctionDetailPanel/          # 函数详情展示组件
│   ├── FunctionFormRenderer/         # 动态表单渲染组件
│   ├── FunctionCallHistory/          # 调用历史组件
│   └── RegistryViewer/               # 注册表查看组件
└── Services/
    └── croupier/functions.ts         # API服务层
```

### 菜单结构
```
游戏管理 (Game Management)
└── 函数管理 (Function Management)
    ├── 函数目录 (Function Catalog)      /game/functions/catalog
    ├── 函数调用 (Function Invoke)       /game/functions/invoke
    ├── 实例管理 (Instance Management)   /game/functions/instances
    ├── 权限分配 (Permission Assignments) /game/functions/assignments
    └── 函数包管理 (Pack Management)     /game/functions/packs
```

## 核心组件详解

### 1. FunctionListTable
**功能**：通用函数列表表格，支持多种配置和操作

**主要特性**：
- 可配置的列显示和操作按钮
- 支持搜索、排序、过滤
- 多选和批量操作
- 响应式设计
- TypeScript类型安全

**使用示例**：
```tsx
<FunctionListTable
  data={functions}
  loading={loading}
  onInvoke={(func) => handleInvoke(func)}
  onViewDetail={(func) => showDetail(func)}
  showActions={{ view: true, invoke: true }}
  pagination={{ pageSize: 10 }}
/>
```

### 2. FunctionDetailPanel
**功能**：函数详细信息展示面板

**主要特性**：
- 完整的函数元信息展示
- 实例覆盖率分析
- 调用历史预览
- 操作按钮集成
- 紧凑和完整模式

**使用示例**：
```tsx
<FunctionDetailPanel
  function={selectedFunction}
  onInvoke={() => handleInvoke()}
  onEdit={() => handleEdit()}
  compact={false}
/>
```

### 3. FunctionFormRenderer
**功能**：基于JSON Schema的动态表单渲染器

**主要特性**：
- JSON Schema支持
- 自定义UI Schema
- 条件渲染和验证
- 多种控件类型
- 实时验证反馈

**使用示例**：
```tsx
<FunctionFormRenderer
  schema={functionSchema}
  uiSchema={uiSchema}
  onSubmit={(values) => executeFunction(values)}
  validateTrigger="onChange"
/>
```

### 4. FunctionCallHistory
**功能**：函数调用历史时间线展示

**主要特性**：
- 时间线布局
- 状态标识和过滤
- 详情查看和重运行
- 自动刷新支持
- 调用结果展示

**使用示例**：
```tsx
<FunctionCallHistory
  functionId="specific-function"
  limit={20}
  onRerun={(call) => rerunCall(call)}
  autoRefresh={true}
/>
```

### 5. RegistryViewer
**功能**：服务注册表监控和展示

**主要特性**：
- 服务健康状态监控
- 统计信息和覆盖率
- 实时状态更新
- 游戏和环境过滤
- 异常服务告警

**使用示例**：
```tsx
<RegistryViewer
  gameId="game-123"
  showStats={true}
  autoRefresh={true}
  onServiceClick={(service) => showServiceDetail(service)}
/>
```

## 页面重构详解

### 1. 函数目录页面 (/game/functions/catalog)
**功能**：函数浏览、搜索、筛选和详情查看

**主要改进**：
- 从原有GmFunctions中分离出来
- 增强的搜索和过滤功能
- 函数详情抽屉展示
- 版本和状态信息显示
- 覆盖率统计

**技术特点**：
- 使用ProTable组件
- 集成FunctionListTable
- 支持分类和标签过滤
- 国际化支持

### 2. 函数调用页面 (/game/functions/invoke)
**功能**：专用的函数执行界面

**主要改进**：
- 集成函数选择和表单渲染
- Tab页面设计（调用/目录/历史）
- 实时执行结果展示
- 支持同步和异步执行

**技术特点**：
- 多Tab布局
- FunctionFormRenderer集成
- 执行结果格式化
- 调用历史集成

### 3. 实例管理页面 (/game/functions/instances)
**功能**：监控Agent实例和函数覆盖情况

**主要改进**：
- 覆盖率分析和统计
- 实例健康状态监控
- 告警和异常提示
- 详细实例信息展示

**技术特点**：
- 统计卡片展示
- 实时状态更新
- 异常服务告警
- 覆盖率计算
