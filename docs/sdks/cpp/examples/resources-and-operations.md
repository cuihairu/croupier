# 资源与操作示例

资源与操作示例只展示函数能力契约。SDK descriptor 只提供 `resource`、`operation`、`risk`、`input_schema` 和 `output_schema` 等字段；页面分类、动态 labels、页面类型和位置必须在 Page Studio / PageSpec 中确定。
