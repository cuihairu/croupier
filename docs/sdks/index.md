# SDK 文档

所有 SDK 文档统一收敛到当前站点，代码仍然保留在 `sdks/<lang>` 目录。

## 当前结构

- `docs/sdks/js/`: JavaScript SDK
- `docs/sdks/python/`: Python SDK
- `docs/sdks/go/`: Go SDK
- `docs/sdks/java/`: Java SDK
- `docs/sdks/csharp/`: C# SDK
- `docs/sdks/cpp/`: C++ SDK

## 迁移原则

- 面向使用者的正式文档统一放在 `docs/sdks/<lang>`
- SDK 目录中的 `README.md` 保留为开发与发布说明入口
- `sdks/<lang>/docs` 已移除，不再维护独立 SDK 文档站
