# Python SDK 指南

## 连接模型

Python SDK 使用单个双向连接与 Agent 通信，不需要本地额外监听端口。

## 集成建议

- 把业务处理器保持为纯函数或薄封装
- 对耗时任务使用后台任务系统，不要长时间阻塞主调用链
- 将协议升级与 `proto/**` 变更一起评审

## 线程与并发

如需并发处理，优先使用 Python 现有的异步或任务队列机制，不要把 SDK 客户端实例跨进程共享。
