# Java SDK

Java SDK 面向 JVM 服务，提供连接 Agent、注册函数和处理调用的核心能力。

## 代码位置

- `sdks/java`

## 特性

- JDK 17+ 支持
- 适合集成到现有 JVM 服务或 Spring 体系
- 与 monorepo 协议演进统一管理

## 快速开始

```xml
<dependency>
  <groupId>croupier.cuihairu.github.io</groupId>
  <artifactId>croupier-sdk-java</artifactId>
  <version>0.1.1</version>
</dependency>
```
