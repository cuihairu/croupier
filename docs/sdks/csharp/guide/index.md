# C# SDK Guide

## Integration Advice

- Manage the client lifecycle as a singleton in ASP.NET Core or background services
- Keep function handlers separate from DI registration to avoid overly complex startup logic
- Constrain cancellation tokens, timeouts, and log fields uniformly

## Capability Direction

- Configuration management
- Dependency injection
- Error handling
- Async handlers
