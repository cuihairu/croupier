# 运维大屏（舰队健康总览）

> OPS-011 —— 纯前端特性。数据源为既有 OPS API，不涉及后端或
> PageSpec/渲染变更。

运维大屏（`/ops/dashboard`，页面 `Ops/Dashboard`）面向游戏 agent 提供舰队级
健康总览。每 5 秒轮询 OPS API，渲染 best-effort、只读快照。它**不**变更任何
状态，也**不**冒充控制面——drain 等动作仍归属各自专用运维页。

## 数据源

| 关注点           | API                     | 说明                                    |
| ---------------- | ----------------------- | --------------------------------------- |
| 节点资源指标     | `listOpsNodes`          | 实时 CPU/内存 `usagePercent`、状态      |
| 告警事件流       | `fetchOpsAlerts`        | 滚动条剔除已静默告警                    |
| 供给运行（今日） | `listOpsProvisionRuns`  | 计本地日 `createdAt`                    |
| 探针结果         | `listSyntheticsResults` | 按 `gameId\|env` scope 去重，近 10 分钟 |

四源以 `Promise.allSettled` 轮询——单源失败不整体挂；页面保留上次成功快照并
回退到过期横幅。

## 健康档位

节点归入五档：

| 档位       | 颜色 | 条件                                                |
| ---------- | ---- | --------------------------------------------------- |
| `normal`   | 绿   | CPU 与内存均低于压力阈值（默认 60%）                |
| `pressure` | 橙   | CPU 或内存在 `[压力, 过载)`（默认 60–85%）          |
| `overload` | 红   | CPU 或内存 ≥ 过载（默认 85%），**或**窗口内探针失败 |
| `offline`  | 灰   | 状态 `offline` 或 `stale`                           |
| `unknown`  | 浅灰 | 无 CPU/内存样本（不误判）                           |

### 防抖

`pressure`/`overload` 须连续 **3 个轮询周期**才变色（防单次尖峰误报）；
`normal`、`offline`、`unknown` 立即生效。

### 排序

卡片按档位严重度排序——`overload` → `pressure` → `normal` → `unknown` →
`offline`（离线置底）——再按主机名。

## 聚合带

全网节点数、在线率（在线/总数，%）、平均 CPU 与内存（仅计有指标节点）、
今日扩缩容数、活动（未静默）告警数，外加各档位计数标签。

## 过期处理

最后一次成功刷新超过 30 秒（或从未成功）时，顶部横幅提示数据过期；页面展示
最近快照但不将其视为当前状态。

## 下钻

点击节点卡弹出模态框：节点身份/状态/指标 + 每小时资源历史迷你曲线
（`getAgentMetricsHistory`，hourly，近 48 点）。`?agentId=` 深链预选下钻。

## 已知边界

- **账号负载视图**为占位：账号分布数据依赖调度编排的账号分布布局，当前无
  数据源（OPS-002 边界）。视图明确标注「待接入」而非伪造数字。
- **阈值**当前取默认常量（60/85）；网络级可配阈值登记为后续工作。
- 大屏**只读**：不触发动作，探针失败是信号而非强制执行。
