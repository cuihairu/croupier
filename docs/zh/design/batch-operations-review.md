## 2. §9 五问（推荐，供签核）

### D1 — 首批业务域、对象上限、缺省阈值

- **业务域：先邮件+补偿。** 两者同为发放形态（同一 operationId 语义），走通
  快照→预演→审批→派发全链，且与设计 §1 的排序一致。批量封禁第二（账号处置有
  自己的评审面）；批量订单补偿最后（需支付侧先具备逐订单幂等+到账核验）。
- **对象上限：缺省每批 5,000，配置门控**（v1 硬顶；更大名单拆多批——各自独立
  审批）。上限是派发面护栏，不是业务限制。
- **缺省阈值：采用 §4.3 表为出厂缺省策略**（连续 10 次失败或总失败率 20% →
  暂停；参数/权限/契约冲突与预算超限 → 立即暂停+告警）。

### D2 — 存储形态：`BatchOperation`/`BatchItem` 独立表；逐对象事件与 `TaskEvent` 分离

- 新模型 `batch_operations` / `batch_items`（按 schema 迁移契约走编号迁移；
  幂等补列按 0015/0021/0025/0027 模式）。
- **逐对象事件不进 `TaskEvent`。** `TaskEvent` 承载任务进度/日志，服务任务
  runner 的消费者；批次对象状态机（§5.2：pending→ready→dispatching→running→…、
  cancel 分支）状态集、查询形态、保留曲线都不同。混载会破坏任务消费者并强共索引。
  批次事件独立建表，键 (batchId, itemId, seq)——批次回放/恢复读它，任务页永不读。
- 批次经任务面派发时 `batchId` 关联 `TaskRun`，但批次身份与任务身份保持区分
  （任务重试绝不能别名化批次对象的终态）。

### D3 — 预演有效期与过期

- **缺省有效期 24h，按域配置门控。** 过期 → 重跑预演+重新审批（设计 §3 已强制；
  此处定数）。
- 经游戏版本号的增量校验仅在**函数契约声明版本支持**时启用（设计自身条件）；
  名单仍绝不静默修改。

### D4 — 重试权限归属

- **值班运营持专用权限键**（既有 RBAC 面内 `batch.retry`）为主归属：他们握有
  运营上下文，既非发起人（自审批压力）也非审批人（职责分离）。
- 发起人可在未过期时重试**自己的**批次；审批人不自动获得重试（审批与再派发是
  不同职责）；管理员走既有 admin 族。
- 重试 = 只派发非终态对象（§5.2 恢复规则；succeeded/failed/conflict/canceled
  永不重放）。每次重试写审计（操作者+范围）。

### D5 — 从失败/未知对象一键生成补偿草稿

- **可以——一键生成的是 DRAFT，绝不是已审批批次。** 草稿携带：来源批次
  batchId、逐对象原 operationId + 凭据/查询位置、原快照摘要，以及自身的全新
  冻结+预演。
- 再审批摘要必须展示（设计 §6.6 + 本补充）：来源批次、失败与未知对象计数、
  每个对象可安全再派发的原因（失败且有未发放证据 / 未知经查询收敛）、新批次
  总预算、函数契约版本。
- 审批永不继承（约束性，§6.6）。

## 3. 单位与倍率（设计留白的收口）

设计在 §4.1 提到「currency and decimal precision」但倍率语义留白。提案：

- 金额存**整数最小单位或精确十进制字符串 + 币种码**——绝不用浮点（浮点存钱是
  缺陷类，不是风格问题）。
- **倍率在冻结前解析**：补偿包 ×N、VIP 档系数等在预演/快照时算成逐对象具体
  金额；快照存解析后金额（倍率作为出处记录）。执行器只派发解析后金额——
  绝不在派发时做乘法。
- 冻结后倍率变更 = 参数变更 = 新快照+重新审批（§2.2 约束性规则原样适用）。
- 币种换算 v1 范围外：单批次单一币种；混合币种名单在冻结时以显式原因排除。

## 4. 依赖（实施顺序）

1. **GAME-009 协议**（operationId + 指纹去重 + 凭据）——批次 §6 逐项复用；
   没有它，exactly-once 无从谈起。GAME-010 实施是后续项，且对真实游戏侧本身
   「仍 NOT RUN」（见 todo）。
2. **审批链**（既有 SQLStore CAS workflow）——不变消费者。
3. 批次表+页面在本评审批准后才落地（设计文档头部的自设闸门）。

## 5. 验收确认

设计 §8 七个场景作为实施的验证基准成立（恢复、名单变更、逐对象对账、丢失
响应、预算护栏、暂停恢复、失败阈值）。本评审增补一个：

8. **单位/倍率**：补偿包 ×3 在快照时解析逐对象金额；审批后倍率变更阻断执行
   并要求重新审批；对账总额等于解析后金额之和、为批次单一币种。
