# Java SDK

Java SDK 面向 JVM 服务，提供连接 Agent、注册函数与处理调用的核心能力。

## 代码位置

- `sdks/java`

## 特性

- 支持 JDK 17+
- 贴合既有 JVM 服务或 Spring 生态
- 协议演进与 monorepo 一起管理

## 快速开始

```xml
<dependency>
  <groupId>io.github.cuihairu.croupier</groupId>
  <artifactId>croupier-java-sdk</artifactId>
  <version>0.1.1</version>
</dependency>
```
