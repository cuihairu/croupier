# Java SDK API

当前 API 文档以 `sdks/java` 的源码与生成类型为准。

## 核心对象

- `ClientConfig`
- `CroupierClient`
- 相关 descriptor 与 handler 类型
- `OpenAPIImporter` / `OpenAPIImporter.ImportOptions`（OpenAPI 3 导入，支持 Descriptor v2 的 capability/execution/approval 扩展）
