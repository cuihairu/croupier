# Dashboard glossary

> **Status**: Current -- this document defines the current model only. Any historical page model not appearing here is not current terminology.

| Term                        | Definition                                                                                                                                                        | Not what it is                          |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| FunctionContract            | A version, input/output JSON Schema, governance, and limited capability semantics of an executable function                                                        | A page or menu configuration            |
| ResourceCapability          | The set of function capabilities aggregated around one business resource                                                                                          | A database table or direct business-data API |
| CapabilitySemantics         | Verifiable business semantics of a resource's identity, collection, CRUD, and action/task/report                                                                  | Column or button positions, page layout, or mapping JSON |
| Resource Catalog            | The platform entry point for managing and reviewing CapabilitySemantics                                                                                           | Page Studio or a business CRUD API      |
| PageProposal                | A traceable page proposal generated by the Server from capabilities and semantics                                                                                 | A user draft or a runtime page          |
| ProposalKey                 | The generator's idempotent identity: `resource:<resourceKey>` or `<kind>:<functionId>`                                                                            | A menu title or a random page ID        |
| PageIdentity                | The published-page identity of `game_id + env + pageKey`                                                                                                          | A function ID or an overridable scope in the URL |
| PageDraft                   | The editable page version after a user accepts a Proposal                                                                                                         | An auto-overwritten generation cache    |
| PublishedPageSpec           | An immutable runtime page snapshot with a validated, frozen contract digest                                                                                       | A live projection of the latest function |
| BindingFreshnessDiagnostic  | A read-only drift report between a published snapshot and the latest FunctionSpec (input/output/governance/execution/function missing); syncing still requires an explicit merge and republish | An auto-invalidation or silent-switch signal |
| BindingFreshnessStatus      | `fresh` / `contract_missing` / `function_missing` / `input_schema_stale` / `output_schema_stale` / `selector_stale` / `governance_stale` / `approval_stale` / `execution_mode_stale` | A page quality enum |
| ThreeWayMerge               | A three-way merge of the base proposal snapshot, the current draft, and the latest proposal: presentation fields merge automatically, execution fields enter the manual conflict set | An automatic sync that accepts the latest contract wholesale |
| BlockedProposalIssue        | Diagnostics and remediation guidance for when a page cannot be materialized safely                                                                                | A Proposal carrying `blocked` quality   |
| SemanticProvenance          | The source, digest, and confidence of every valid or conflicting semantic field                                                                                   | A single source field                   |
| ApprovalPolicy              | Approval requirements and policy references, orthogonal to sync/async execution                                                                                   | A fifth page type or an execution enum value |
| ResourcePage                | List, detail, CRUD, and resource-action pages around one resource                                                                                                 | A container for all functions           |
| OperationPage               | Form, confirmation, and result pages for a standalone synchronous command                                                                                         | A stripped-down CRUD page               |
| TaskPage                    | A page that starts and tracks an asynchronous task                                                                                                                | A result box that only shows a taskId   |
| ReportPage                  | A page of queries, datasets, metrics, dimensions, and charts/tables                                                                                               | Arbitrary JSON output                   |
| PageBinding                 | The identity, input/output selectors, and governance constraints that execute one function under control within a page                                            | A functionId the browser may call freely |
| Typed Selector              | A restricted AST referencing form/row/selection/detail/page state/literals                                                                                        | Arbitrary JSONPath or blind whole-row passthrough |
| FormPresentationSpec        | Field order, grouping, widget hints, and visibility configuration for a JSON Schema form                                                                          | A FunctionContract or a page layout tree |
| ConsoleMenuSpec             | The Console's dynamic menu generated from active PublishedPageSpecs                                                                                               | A function catalog, a dictionary, or static locale data |
| Scope                       | The global `game_id + env` context                                                                                                                                | An overridable parameter in the page URL or payload |

The base DTOs (`Scope`, `FunctionRef`, `SourceDigest`, `Diagnostic`, `LocalizedText`, `JsonPointer`, and the JSON value types) are defined exclusively by the [Dashboard resource/page model](./dashboard-page-model.md); the frontend shared types and the Go DTOs must correspond item by item, and must not be redefined inside pages or components.

## Common boundaries

```text
FunctionContract answers: "How is this capability invoked?"
CapabilitySemantics answers: "What does it do in the resource lifecycle?"
PageSpec answers: "How does an operator complete the business task?"
ProComponents renderer answers: "How is this page displayed in React?"
```

If a field tries to answer questions at more than two of these layers at once, split the model instead of adding generic metadata.
