# 四类 Agent 接口 scope 隔离矩阵（AGENT-001，2026-11-01）

日期：2026-11-01。范围：capture / devops / sidecar / synthetics 四类 Agent **当前已支持**的注册 / 配置 / 列表 / 统计 / 详情 / 动作 / 日志 / 离线读取接口，逐项核对 scope 隔离（fail-closed 与否）并给出测试证据；复用既有非空 scope 与绑定测试，覆盖同 ID 冲突与跨 scope 指派；devops 未接通的会话 / 回放列 NOT IMPLEMENTED，无假数据。

方法：HTTP/wire 路径逐条核对（scope 来源 → 过滤/拒绝行为 → 既有测试），缺测试的当场补（见「本轮修复与新增」）。矩阵中「隔离」指：请求 scope（`X-Game-ID`/`X-Env` 头，`GameDBMiddleware` 注入并鉴权，见 `internal/svc/game_middleware.go:48`）与目标数据 scope 不匹配时 fail-closed，而非仅靠列表侧过滤。

## 2. 同 ID 冲突与跨 scope 指派

- **同 ID 冲突**：同 agentID 已绑定 `(game_id, env)` 后跨 game/env 再注册 → fail-closed 拒绝（`already bound to game_id`）；同 scope 重连放行且原会话 scope 不被污染。证据：`TestHandleRegisterRequest_SameAgentIDCrossScopeRejected`。
- **跨 scope 指派（路由侧）**：dispatcher 选路只命中请求 scope 的 agent，跨 game/env/过期/draining 一律拒绝。证据：`TestDispatcher_pickAgentWithRouting_FiltersGameEnvironment`（`dispatcher_test.go:784`）、`TestAgentCanInvoke_Matrix`（`routing_scope_test.go:47`）。
- **跨 scope 指派（动作侧，本轮补）**：修复前 `/ops/nodes/:nodeId/{drain,undrain,restart,meta}` 只按 nodeId 解析连接，A scope 管理员可对 B scope 节点执行动作——与同组列表/详情的 scope 口径漂移。修复后统一走 `requireAgentScope` fail-closed（`TestOpsNodeDrain_CrossScopeRejected` 等 3 例）。

## 3. 边界与已知缺口（诚实清单）

### 3.1 synthetics 离线读取的 scope 来源是 query

`/ops/agents/synthetics/results` 读 `c.Query("gameId"/"env")`（`synthetics_results.go:36`），是该组内唯一不走 header scope 的端点：行级隔离成立（返回且仅返回所查 game/env 的 probe 记录，`Recent(ctx, gameID, env, ...)`），且前端契约显式传 query（`web/src/services/api/ops`）。但**所查 scope 未对 header 已授权 scope 再校验**——请求头 scope A + query scope B 时返回 B 的记录。属遗留 query 契约与 header 约定（作用域规范）的漂移，本轮不改行为（改 query→header 需同步前端契约与既有测试），登记为已知边界，建议随 synthetics 面板迭代对齐。

### 3.2 devops 会话 / 回放 NOT IMPLEMENTED（无假数据）

agent 侧已有 `agents/devops/session/` 的 Broker（建立链：校验→白名单→审计准入→Provider 打开）、Hub（有界队列/背压/Attach 接线点）、recorder/asciicast 归档（`agents/devops/runner/runner.go:138-156` 已装配），但 **server 侧无中继、无任何 HTTP 路由**（`routes.go` 无 sessions/playback/asciicast 端点），回放归档仅存 agent 本地。故矩阵「会话/回放」列 **NOT IMPLEMENTED**，不以占位端点或模拟数据充当验收；随 AGENT-002（中继）/AGENT-003（界面）验收。

### 3.3 平行的无 scope 节点面（by design）

`/api/v1/nodes/**`（`registerNodeRoutes`，`routes.go:164/540`）挂在无 `GameDBMiddleware` 的 protected 组，整组不做 game/env 过滤——集群级节点管理面（含 cron-jobs 视图），与 `/ops/nodes/**` 是两个交付面，非本矩阵缺口。

### 3.4 冗余实现

`internal/api/ops/nodes.go` 的 `NodeService`（Drain/Undrain/Restart/GetMeta/GetCommands 自带 `requireAgentScope`）**未接线到任何路由**，仅测试引用（`simple_test.go:914` 等）——先于本轮修复存在的死实现。live 路径（helpers.go）本轮已补同款 scope 门，二者行为一致；后续可择机删除死实现收敛单一来源。
