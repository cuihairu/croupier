# GUX-003 运营首页 — 交付证据（2026-11-17）

## 改动面

### 落地规则（根路径 `/` 按角色能力重定向）

- `web/config/routes.ts`：`/` 由 `./Welcome` 改为 `./LandingRedirect`。
- 新增 `web/src/pages/LandingRedirect.tsx`：按现有 access 权限取第一个可进入工作区
  —— `canConsoleRead` → `/console/home`、`canFunctionsRead` → `/functions/catalog`、
  `canSystemConfigRead` → `/system`，全部不可见回退 `/account`（个人中心）。
  权限为 bootstrap 时 profile 派生，此组件只读不请求；`history.replace` 落地，
  刷新不产生历史回退环。

### 移走产品建设说明（Welcome 模板页下线）

- 删除 `web/src/pages/Welcome.tsx`（hero/journey/资源入口的产品建设说明页）与
  未路由的模板残留 `web/src/pages/Admin.tsx`（"use block"/双心模板文案，
  `component: './Admin'` 无任何路由引用，`src/pages/Admin/` 真实页面不受影响）。
- locale 清理：删除 `zh-CN/welcome.ts`、`en-US/welcome.ts` 命名空间与两个聚合器
  的 import/spread；`menu.welcome`（8 个 locale）与 `pages.welcome.link`/
  `pages.welcome.alertMessage`（8 个 locale 的 pages.ts）同步移除——原唯一消费者
  即下线的两个模板页。`app.welcome.*` 聚合器内联键按计划留给 GUX-015 文案收敛。

### 运行控制台首页挂运营工作台

- 新增 `web/src/pages/Console/Workbench.tsx`，`Console/index.tsx` 仅根视图
  （无 categoryKey）在概览卡上方挂载；分类页保持纯页面导航。
- 四块面板，全部按现有权限派生、无新后端接口：
  - **待办**：审批待办（`canAuditRead` → `listApprovals({status:'pending'})`，
    行内 functionId/actor/时间，点击去审批中心）+ 未读消息（登录即可，
    `unreadCount()`）；
  - **异常**：契约失效页面计数与 pageKey 列表（来自已加载的发布页清单
    `bindingFreshness`，零额外请求）+ 运维告警（`canOpsRead` → `listAlerts`）；
  - **最近处理**：`listExecutionLogs({mine:true})`（无需审计权限），
    状态 Tag + 时间；「执行记录」入口链接仅 `canAuditRead` 可见；
  - **常用入口**：审批中心（audit）/五个业务模板（常驻）/菜单管理（page）按权限过滤。
- 面板契约：单面板失败只显示该面板错误 + 重试，不拖垮整页；权限外面板整体
  不渲染；空数据渲染真实空态；审批面板随 `useScope().scopeKey`（游戏/环境切换）
  重拉。locale 键入 `pages.console.workbench.*`（zh-CN/en-US consolePage.ts）。
- 入口按钮图标（audit/menu）标 `aria-hidden`：装饰图标名不混入按钮可及名。

### 测试基建修复（连带收益）

- `web/tests/setupTests.jsx`：`window.matchMedia` mock 由 `jest.fn` 改为普通函数
  ——`jest.resetAllMocks()` 会清 jest.fn 实现，matchMedia 返回 undefined 曾令
  antd6 responsiveObserver（Row/Col）直接崩；同时补 `addEventListener`/
  `removeEventListener`（antd6 守卫路径）。
- 同文件 console.error 过滤器：React 19.2 起 act 告警文案由
  `Warning: An update to %s inside...` 变为已插值的组件名，原精确匹配失效，
  改为子串匹配两种格式。
