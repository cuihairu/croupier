# GUX-015 · 说明与文案收敛（2026-11-17）

## 改动面

### 1. 函数目录（`web/src/pages/Functions/Directory/index.tsx`）：重复引导 → 按需帮助

原首屏引导质量：hero 渐变卡（intro 标题/描述 + 「当前建议动作」「这里适合确认什么」双引导子卡）+ SummaryOverview hint 行 + 两张常驻 info Alert——同一句「函数目录不承载页面 UI，去 Page Studio / 资源候选」重复出现约 6 处，函数列表被推到第三屏之后。

现在：

- **默认可见**：数据标签行（能力供给层 / 可装配函数 / 已声明操作 / 最大资源，全部实时计数，原样保留但移出渐变卡）+ SummaryOverview（保留 description 一行分层说明，删除 hint 行——与 description 同义重复）+ 函数列表。
- **按需帮助**（一张默认折叠的 `Collapse`，header「使用说明与常见误解」）：分层职责（intro 标题/描述）、当前建议动作（两个跳转按钮原样保留）、检查要点（3 Badge）、常见误解 1（只展示能力供给）、常见误解 2（目录状态 ≠ 开放范围 + 「前往函数开放范围」按钮）。
- **去重**：原 Alert「查看资源」与建议动作主按钮同目标（resource-catalog），收敛后仅保留后者；`button.viewResources` 键删除。
- 首屏引导从约 270 行收缩到一行折叠条 + 数据卡。

### 2. 页面工作台（`web/src/components/PageWorkflowGuide/index.tsx`）：整卡引导 → 折叠条

原 Card 内 Steps 四步流程 + 常驻 warning Alert 在工作台首屏全量展开。现整体折叠为一条默认收起的 `Collapse`（标题「创建完整页面：只走这一条默认路径」常驻），Steps 与提醒展开后可见。消费方 `PageStudio/index.tsx` 的挂载点不变；全部 PageStudio 测试本就 mock 该组件为 null，无测试面影响。

- 占位符 `pages.login.{username,password}.placeholder` 8 个 locale 全量去模板名：`用户名: admin or user`→`用户名`、`密码: admin`→`密码`（zh-CN/zh-TW/en-US/ja-JP/bn-BD/fa-IR/pt-BR/id-ID 同步）；组件 `Login/index.tsx` 的 defaultMessage 同步改（无兼容旧值）。
